# 账户身份确认与表单反馈修正

日期：2026-11-04。延续用户对工作台、表单和说明文字的精简反馈；仅前端实现与本地 Docker 验证，未发布。

## 身份确认

- 共享身份确认读取当前账户 `/security/mfa` 的 `enabled`，未启用时只显示密码，启用后才显示必填验证码。强制 MFA 策略不等于已绑定身份验证器。
- 项目密钥、开发者调试 Key、管理员操作、服务商与策略的身份复核共用此规则；普通价格与恢复价格两处独立确认也改用同一验证码组件。
- 状态加载时不虚构验证码要求；失败时提供重试。确认弹窗在状态未知、加载失败或缺少已启用账户的验证码时禁用提交，包括 Enter 提交路径。
- 停用身份验证器后清除表单旧验证码，保留用户正在输入的密码。MFA 设置变更继续使共享状态失效并刷新。
- 登录仍按服务端返回的 MFA challenge 显示验证码，登录 UI 未修改。首次绑定的验证码用于确认新设备；撤销、恢复码与停用等已启用账户的专属流程保留验证。

## 错误反馈与文案

- 工作台新建 Key 的正常身份复核提示原本被主表单重复渲染成失败；现由确认弹窗统一处理，真实失败仅显示一次，取消后不会在主表单残留。
- 普通表单和弹窗的错误提示与前项增加标准间距，已有表单布局继续负责自身间隔；登录布局不受影响。
- 图片提示改为「需视觉模型。本地图片不落盘；远程图片由上游读取，不提供预览。」英文同步短化。
- 创建项目的请求限制、延迟取回、运行治理与安全访问说明进一步精简，保留配置默认值和必要后果。
