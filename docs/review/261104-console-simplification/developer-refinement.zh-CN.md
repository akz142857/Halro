# 开发者工作台第二轮精简

- 日期：2026-11-04
- 起因：第一轮精简后，用户仍认为工作台文字和层次过多，授权重排结构与交互。
- 范围：开发者工作台、对应双语文案与共享 Modal 的键盘边界修正；登录页保持原 UI。
- 设计依据：任务优先、渐进披露、减少重复、状态出现时再呈现相关信息。沿用[现有 Apple HIG 采用原则](../../prd/console-interface-simplification.zh-CN.md#apple-hig-的采用方式)，没有另起主题或组件框架。

## 实现

| 原结构 | 新结构 |
| --- | --- |
| 请求、接入代码、响应三块同时竞争首屏 | 默认只呈现请求与响应；页头明确提供「接入代码」入口 |
| 项目筛选、转发目标和说明常驻 | 请求标题旁保留项目摘要与「连接设置」，设置内展示项目筛选和计费归属说明 |
| Gateway 地址出现在调试主表单 | 只在接入代码抽屉编辑，明确它仅影响代码示例；真实调试始终进入当前实例 |
| Key 内存、真实计费、身份复核和有效期多段常驻 | 主输入旁短标注「仅当前页」；完整内存边界在连接设置；真实可计费、身份复核和 24 小时有效期在新建 Key 确认中 |
| 代码面板已出现，却还要再次「展开代码」 | 打开抽屉即显示完整示例；语言和复制操作位于同一工具栏 |
| 响应尚未产生就显示七格空指标和解释 | 空闲时只显示简短等待状态；请求发出后才展示 HTTP/延迟/实际计费/费用等证据 |
| 普通响应与 SSE 两个大选项 | 发送旁使用流式复选框；Embeddings 的限制仍明确展示 |
| 默认显示零图片、字节数等未使用信息 | 图片未添加时只保留展开入口；字节数进入代码抽屉的 POST 路径摘要 |

发送前的费用后果始终可见。未知费用、估算、跨项目计费、错误原因、取消、流式、历史重放和 JSON 覆盖语义均保留。没有通过字体缩小或降低对比度实现减量。

## 对照测量

同一合成 API 数据、简体中文、Dark、1440×900 视口，比较第一轮生产 bundle 与第二轮代码：

- 默认辅助文字从 285 降至 34 字符，约减少 88%。字段标签、配置值、旧七格元数据标签和代码内容不计入此指标。
- 发送按钮顶部由 1134px 提前到 756px；模型、Key、输入、流式和发送均可在桌面首屏完成。
- 整页高度从 1297px 降至 919px；窄屏允许自然纵向操作，空闲响应使用更紧凑的占位，不要求将所有控件挤进同一屏。

同条件合成数据截图：[改造前](developer-before.png) · [改造后](developer-after.png)。[机器汇总](developer-validation.json)保留各宽度量化与精确复验链。

## 审查与回归

- 原有 31 项工作台行为覆盖保留，新增空闲指标、两个浮层保留状态、实际计费边界和代码抽屉 Tab 循环等回归。
- 独立源审查确认：Gateway 地址不阻断调试；关闭浮层不清空输入/Key/JSON/结果；代码仍使用环境变量；实际账本与 Key 决定费用归属。
- 浏览器发现并修复：流式标签被挤成竖排、长项目名挤压连接按钮、窄屏单列的 min-content 导致横向溢出。
- 无效 JSON 时复制按钮被禁用，原 Modal 将 `tabIndex=-1` 的语言按钮错误纳入焦点末端，导致 Tab 逃出抽屉。共享焦点范围现排除显式负 tabindex，并用共享及真实工作台回归验证。
- 代码抽屉内长代码保留局部滚动；滑入动画由背景层约束，页面不承担横向滚动。
- Token 间距基线由 679 降至 669；原登录页文件与基线保持一致。
