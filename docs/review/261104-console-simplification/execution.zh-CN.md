## 2. 服务商试点量化

条件：1440×900、100% CSS 视口、简体中文、Dark、已有兼容 OpenAI 凭据、普通新建服务商。中文辅助说明按可见元素 `innerText` 计字符；标签、真实配置摘要与风险告知单列，不混入辅助文案计量。

| 项目 | 基线 | 新版 |
| --- | --- | --- |
| 默认可见普通辅助文字 | 250 字符 | 0 字符 |
| 原 9 条普通说明的去向 | 默认显示 | 7 条删除，2 条进入相关折叠区 |
| 基础必需字段是否完整位于首屏 | 否 | 是，最后一个基础字段底边为 521px |
| 普通创建的点击数 | 2 | 2 |
| 能力呈现 | 标签摘要加完整编辑列表 | 单个折叠编辑区与所选数量 |

点击数通过浏览器事件记录：打开创建弹窗、填写名称后提交；输入操作及进入页面的导航不计入。该数字仅适用于已有兼容凭据的普通路径，不代表首次部署或特殊接口的步骤数。风险告知没有被纳入「250→0」的删减指标。

## 3. 共享组件与视觉收口

- 登录页按用户追加要求恢复为原双栏品牌与表单布局、原文案和原 MFA 标题层级；本轮其余页面的精简改造继续保留。
- `PageHeader` 的眉题/说明可选；`EmptyState` 允许标题和恢复操作独立成立，不渲染空说明段落。
- `DisclosureSection` 原生键盘可达，保留挂载值与 dirty；摘要反映配置；RHF 与原生校验均可展开，重复提交也可恢复。
- Modal 焦点循环包含 summary，排除闭合区的后代；自动聚焦表单关闭后返回原触发器。
- 服务商基础表单约 800px，按内容适配窄屏；项目和部署折叠区沿用统一内边距。
- 开发者发送栏移回正常文档流，消除输入遮挡；图片帮助按需显示，POST/路径合并，元信息不再挤成窄列。
- 正常状态不使用大块警告；禁用按钮的语义样式不再被 primary 等外观覆盖。
- 表格滚动容器建立定位上下文，防止只读原因的 `.sr-only` 将整页撑宽。
- 未添加颜色字面量或新主题；复用现有 Token。手写间距精确基线由 691 降至 679。


`--quick` 执行桌面全页与弹窗冒烟；`--baseline` 关闭仅针对新布局的断言；`--states` 执行只读、空数据、强制 MFA 和 API 失败。`SCENARIOS`、`WIDTHS`、`LOCALES`、`APPEARANCES` 可限定复验范围。旧版和新版必须使用各自独立预览地址。

### 证据边界

- 所有业务调用使用隔离合成 API；UI 任务链通过不表示新增了真实服务商或生产连通性证据。
- 200%/400% 场景使用与缩放对应的 CSS 视口重排验证；不将其称为操作系统或浏览器工具栏缩放实测。
- 读屏相关验证基于语义、ARIA 和浏览器可访问树；不宣称实际运行了 VoiceOver。
- 主矩阵不是所有业务状态的笛卡尔积。动态错误、订阅、付费提示、秘密和依赖拒绝还由直接相关回归覆盖，特殊接口沿用已有真实契约，不编造能力。
