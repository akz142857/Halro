# 项目 AI 接入与目录间距

日期：2026-11-04。在「项目与密钥」的项目详情中增加「AI 接入」，并修复「系统配置」签名模型目录标题与当前来源之间的间距。登录页面保持原样。

- 入口按当前项目生成，选择范围仅限该项目授权的公共模型别名；支持 Responses、Chat Completions、Embeddings，网关地址可按应用运行环境调整。
- 支持复制接入说明与下载 UTF-8 `SKILL.md`。两者正文完全一致，预览默认收起；复制失败、下载失败与成功反馈独立。
- 开发者工作台和项目导出共用请求体、接口路径、地址校验与代码生成器。支持根地址、`/v1` 和代理路径，避免重复拼接 `/v1`；拒绝带凭据、查询参数或片段的地址，不将管理控制台地址猜作网关地址。
- 密钥使用 `HALRO_API_KEY` 环境变量占位。导出只选择项目标识、别名和配额等明确字段，不读取或创建密钥、不发起模型调用。说明区分项目 ID 与认证、Key 所属计费项目、`inference` 与可选 `discovery` 权限，并提醒确认部署的协议能力。
- 停用项目或没有授权模型时保留入口并说明原因，禁用导出；只读账户与关闭开发者工作台的实例仍可导出。晚到的地址查询不会覆盖手动输入，切换项目不会沿用上个项目的模型。
- `SKILL.md` 含合法的名称与描述元数据、项目上下文、请求示例、响应处理和验证要求。项目名与别名仅作 JSON 数据；围栏长度及字符串转义覆盖特殊字符，不把用户配置当作操作指令。
- 签名模型目录取消重复嵌套标题框，使用独立标题行；当前来源与标题分隔线间保留 12px 内间距，长摘要完整换行，桌面和窄屏共用同一组 Token。
