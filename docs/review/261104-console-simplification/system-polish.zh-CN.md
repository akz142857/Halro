# Console 全系统二次收口

日期：2026-11-04。本轮基于已在本地运行的上一版界面，再审整个控制台的重复说明、长文案和提示间距；登录页保持不变。主 Agent 与配置链、观察治理、共享布局三个 Agent 协作，未修改 Go、API 或权限判定。

## 覆盖与取舍

| 区域 | 本轮处理 |
| --- | --- |
| 总览与接入向导 | 删除页头、步骤列表、页脚对同一任务的重复介绍；当前任务、错误恢复、只读限制与进度保留 |
| 服务商、凭据与部署 | 精简产品和接口说明、能力边界、验证结果；删除绑定详情前言和凭据依赖复述。费用、订阅、证据来源与代理信任边界保留 |
| 路由、项目、策略与脱敏 | 精简停用/绑定说明和重复单位帮助；保留 0 值、访问规则、未知能力及不可逆价格/删除后果 |
| 用量、失败与治理 | 删除表行类型和结果详情的重复介绍；保留 attempt/request 区别、费用未知/估算、真实报表范围、时区代际及冻结版本语义 |
| 告警、审计与集群 | 精简空态和长说明；保留更换密钥接收目标、永久销毁、审计链状态、本节点视角与切换隔离要求 |
| 通用、语言与登录安全设置 | 语言选择器由卡片标题提供可访问名称；去掉第二份可见标签。MFA 不再重复显示启用状态和零设备数量；恢复码及设备撤销告知保留 |
| 实例配置与诊断 | 删除重复分区介绍、正常快照复述、重复更新时间；短化配置来源、热重载与吞吐解释。诊断结论和风险常驻，参数与原始算式按需展开 |
| 开发者工作台 | 合并新建 Key 的重复确认，保留一次显示、退出后有效、24 小时过期与真实计费；精简错误恢复和内存说明，图片输入明确标为「图片地址」 |
| Setup、404 与全局壳层 | 复核现有短版；初始化与全局权限/时区等必要信息保留。没有为覆盖页面而制造改动 |
| 登录页 | 排除内容和布局修改；源码、使用的中英文文案以及截图另行对照验证 |

长文案不按固定字数截断。143 条配置链较长文案逐项分类保留；例如价格建议/费用、订阅条件、代理 CA 与服务商联网边界，需要在用户作决定的位置完整说明。用量图的真实返回时间范围也保留：筛选控件可能为空，切换时还可能短暂显示上一份报表，不能仅凭输入值推断账期。

## 可复核变化

- 中英各改写 155 个文案键，删除 21 个已无调用的说明键，新增 1 个图片地址标签。所有插值参数保持一致，语言资源键完全对齐。
- 被改写的中文字符串合计 7,300→4,615 字符；英文 19,890→12,505 字符。该计量只统计改写短语，不是整个界面的可见文字密度或首屏比例。
- 修正两处误导：未枚举模型不再被描述为上游无列表；停用脱敏不再暗示绕过已配置的代理。
- Gateway Key 错误提示不再把当前项目筛选器当成密钥归属限制，实际计费仍由 Key 与账本决定。

## 间距与交互

- 通用网格字段移除重复块外边距，真实路由表单的行间隔 32→16px。
- 声明了 `gap` 的表单、详情与反馈容器负责自身间隔，notice 不再额外叠加上下边距：表单网格 16px、设置表单 14px、能力检测 12px、用量提示 16px。
- 普通块布局的提示与前后操作保留 12px 分隔；表格/折叠区末尾提示由容器内边距收口。
- 修正诊断卡片层叠覆盖产生的额外 24px 内边距。价格表单的网格分组仍保留外侧 16px 分隔。
- 诊断依据采用原生 details，摘要触达区域为 44px，参数与算式间隔 12px；结论、警告与未知状态不随依据折叠。
