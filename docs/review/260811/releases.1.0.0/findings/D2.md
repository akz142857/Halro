- 修复方向：若产品认可当前色相是有意选择（品牌克制感），应在 tokens.css 的注释或 260810 的整改记录里显式写"色相变更推迟/不做"，而不是让报告停留在"待处理"状态；若要处理，需重新挑一组仍过 AA 的更亮绿并用同一 `design-system.test.ts` 里已有的对比度断言（第 96-136 行）复核。
