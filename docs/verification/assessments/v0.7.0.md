## Findings closed by this remediation

- Added the v0.7.0 changelog, operator impact, comparison link, frontend package
  version, and refreshed dependency-review hashes.
- Corrected release artifact verification to the certificate identity actually
  issued for the official `workflow_dispatch` path:
  `release.yml@refs/heads/main`. Tag-push identity is documented separately.
- Standardized the `en-US` catalog and public/runtime English to American
  English; rewrote count-bearing text so one item cannot render with a plural
  noun or verb; synchronized both endpoint-manifest goldens.
- Added localization regression tests that reject British user-visible
  spellings and unsafe singular count forms.
- Added the missing populated v0.6.0 → v0.7.0 upgrade/restore evidence and the
  missing same-host v0.6.0 performance comparison.
- Performance sampling found and closed two additional defects before this
  assessment was filed:
  - ordinary Ledger events serialized a zero `RunExpiresAt`, inflating every
    record and slowing replay;
  - attached requests held an exclusive governance lifecycle lock across the
    durable append, serializing one Run and cutting its high-concurrency
    throughput by up to about 90%.

  Zero values are now omitted, ordinary replay skips empty attribution lookup,
  and attached request acceptance shares the read side of an RW lifecycle lock.
  Work Unit/Run create and close keep the write side, so the ordering contract
  remains fail-closed while group commit remains available.

## Performance

The [paired evidence](../performance/2026-09-06-v0.7.0/README.md) uses one Apple
M4 host, Go 1.26.6, `GOMAXPROCS=4`, compiled test binaries, serial execution,
and six samples per version.

- No candidate time regression is statistically significant at α=0.05.
- Ledger open/replay for 100,000 records is 542.2 → 555.7 ms, `p=0.240`.
- Route resolution, redaction, Token Guard, and project admission have no
  significant slowdown.
- Within the candidate, all nine Run-attributed lifecycle combinations have no
  significant difference from ordinary request lifecycles after the RW-lock
  fix.
- The initial pre-fix samples are not used as release evidence; they served as
  defect discovery and were replaced by post-fix raw samples.

These are local component measurements, not provider-latency, KMS, or
production-SLO claims.

## Localization and copy boundary

All `en-US` values are checked as user-visible values rather than key names, so
wire/status identifiers such as `cancelled_at` remain compatible while the UI
renders “Canceled.” The review covered the complete English locale catalog,
hard-coded UI prose, runtime/admin error text touched by the catalog and
compatibility surfaces, README, and current operator/user/release guides.
Historical review records and changelog entries were not rewritten because
they are immutable evidence of earlier releases.
