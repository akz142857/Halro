## Range review and defect triage

Reviewed the aggregate production diff: scope controls preserve the requested
permissions while a write is pending and reject empty keyboard submission;
account handlers clean up listeners and restore focus on Escape; list URL edits
preserve unrelated parameters and distinguish replacement from history entries;
usage shortcuts retain exact instants and compute Today in the accounting zone.
Read-only server enforcement, model APIs, accounting and durable formats are
unchanged. There are no confirmed blocking findings or newly introduced
unresolved work markers. The live open bug-label query returned no issues.

The jsdom 31 CSS engine exposed a test that omitted real design tokens. The
fixture now loads those tokens and checks sans-serif plus 13px; production CSS
was not weakened. Legacy-peer timing tests were stabilized in an earlier PR.

Formal publication is authorized after the required gates pass. Merge the
