# Page patterns

> 本文出现的 Wide / Regular / Compact / Small 指 `foundations.md` 的响应式模式定义（> 1120 / 821–1120 / 581–820 / 320–580px），不要按其他文档的同名词理解。

## Overview

结构：PageHeader → 关键 Metric → 趋势/异常 → 次级活动。指标先回答“是否正常”，图表回答“何时变化”，明细回答“为什么”。空数据不伪装为健康。

## Resource list

结构：PageHeader → tabs/filter/toolbar → ResourceRow/Card → detail/modal。对象 identity 永远高于属性；运行状态和主操作在首层可见。Small 下事实换行或隐藏到 disclosure，但名称、状态和主操作不得隐藏。

页头不再介绍模块职责。空资源给创建入口；有筛选却没有结果给清除筛选入口，二者不可使用同一句「还没有数据」。

## Master-detail

Regular/Wide 可并排；Compact/Small 堆叠或使用 Drawer。选中项保持可见，关闭详情恢复焦点和滚动上下文。长 ID 在自身容器处理，不扩大页面。

## Settings

Wide/Regular 使用左侧分区导航，Compact/Small 使用 Select。每个分区先说明作用域（个人、实例、账户），再呈现表单；保存反馈只出现一次，且与切换后的 locale 一致。启动配置和可热更新设置不得混在同一编辑面。

## Data table

优先保留语义 `<table>`。列语义允许时，Small 转为带 `data-label` 的卡片行；高密度技术表保持局部横向滚动，并让当前任务所需列和操作处于首屏。禁止由 body 承担横向滚动。

## High-risk action

触发器说明动作；ConfirmDialog 明确对象、后果与不可逆性；服务端拒绝在对话框内持久显示。Escape 永远取消，不执行确认。Read-only 原因应在控件附近可读。

## Resource form

基础身份、接口、凭据/模型与当前任务必需选择直接呈现。能力只保留一个编辑区域；连接、请求限制、运行治理与安全等低频配置按语义折叠，标题旁显示配置摘要。正常启用状态使用一个有标签的控件，不再复述「已启用」及通用用途；停用后果仍直接显示。

固定页脚只承载必要状态、取消与一个主操作。字段与错误滚入视口时不被页脚遮挡。特殊接口必需字段、费用提醒、订阅接受项和风险告知按条件出现，不为缩短表单而隐藏。

## Developer workbench

主视图只承载请求与响应。模型、接口、Key、输入与发送直接可达；项目筛选与连接边界在明确命名的设置浮层，接入代码在独立抽屉。抽屉打开即显示代码，语言选择与复制使用同一工具栏。空闲响应不显示空的运行/账务指标；请求后展示真实状态、实际计费归属及费用证据。发送前的费用提醒、新建 Key 的身份验证和有效期告知不能被省略。

## Login / Setup

登录页保留用户认可的原双栏品牌区与登录表单及原文案，不随控制台精简改版。Setup 使用单列任务卡片，保留一次性初始化边界、密码与令牌要求；MFA 保留验证和恢复入口。320px 和 400% 缩放下表单、语言切换、错误与恢复入口都必须可达。

## 诊断结论与依据

结论、风险和「未检查」状态常驻，参数表与原始算式通过原生 details 按需展开。折叠依据不得隐藏失败后果或恢复方向。报表的实际账期仍须明确：输入控件为空或数据保留上一份结果时，不能用输入值替代服务端返回的范围。
